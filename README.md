# Portfolio personal

Portfolio de una sola página para presentar el perfil profesional, proyectos y vías de contacto.

## Stack

- Next.js 16 con App Router
- React 19 y TypeScript
- Tailwind CSS 4
- `next-themes` para el tema claro/oscuro y la preferencia del sistema

## Ejecutar localmente

Se requiere Node.js 20.9 o superior.

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000) en el navegador.

## Comandos disponibles

```bash
npm run lint
npm run build
npm run start
```

## Deploy

El proyecto está preparado para desplegarse en Vercel. Importá el repositorio y conservá los comandos predeterminados de Next.js para build y deploy.
